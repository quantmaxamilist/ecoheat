# Eco Heat ASHP Ltd

Modern marketing website for Eco Heat ASHP Ltd — renewable heating specialists in Preston, Lancashire.

## Stack

- Astro 7 + TypeScript (strict)
- Tailwind CSS v4
- Web3Forms contact form

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Environment

Copy `.env.example` to `.env` and add your Web3Forms key:

```
PUBLIC_WEB3FORMS_KEY=your_key_here
```

## Deploy

Push to GitHub and connect to Vercel. Set `PUBLIC_WEB3FORMS_KEY` in Vercel environment variables.
